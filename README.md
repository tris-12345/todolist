
# Todo List

A full-stack Todo List web application built using **Node.js, Express, EJS, MongoDB, and Mongoose**.

The application allows users to create, manage, and delete tasks while storing data persistently in MongoDB.

It also supports creating custom todo lists using dynamic URL routes.

## Features

- Add new todo items
- Delete completed items
- Persistent MongoDB storage
- Create custom todo lists
- Dynamic routes for individual lists
- Automatically initializes default todo items
- Environment-variable based database configuration

## Tech Stack

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

### Frontend

- EJS
- HTML
- CSS

### Other Libraries

- Lodash
- Body Parser
- dotenv
